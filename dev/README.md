# SORRIMED — Versão Frontend-Dev

Esta é a versão alternativa da landing page da SORRIMED, construída pelo
perfil `frontend-dev` usando as skills `landing-page-from-reference`,
`ui-ux-pro-max` e outras.

## Comparação de versões

| Versão | URL | Construída por |
|--------|-----|----------------|
| Principal | `/` (raiz) | Perfil default |
| Dev | `/dev/` | Perfil frontend-dev |

A versão `dev` tem:
- Hero com foto natural (Unsplash) e blazer rosa pálido
- Seção "Sobre" com foto do interior da clínica
- Cards com hover lift e barra dourada lateral
- Logo oficial versão 2x para telas high-DPI
- Animações reveal-on-scroll via IntersectionObserver
- Formulário de contacto estilo glassmorphic
