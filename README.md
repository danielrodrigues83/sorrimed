# SORRIMED — Clínica Dentária

Landing page oficial da SORRIMED, clínica dentária em Lisboa.

## Sobre

Mais de 20 anos a cuidar de sorrisos em Lisboa, com uma equipa dedicada,
tecnologia de ponta e um ambiente acolhedor.

## Tecnologias

- HTML5 + CSS3 (single-file, sem dependências JS)
- Google Fonts: Cormorant Garamond + Montserrat
- Imagens: Unsplash (mulher sorrindo) + foto oficial do logo

## Estrutura

```
.
├── index.html          # Página completa
├── images/
│   ├── hero-smile.jpg  # Foto do hero
│   ├── logo-official.jpg
│   └── logo-official.png
└── README.md
```

## Desenvolvimento

Servidor local:

```bash
python3 -m http.server 8000
```
